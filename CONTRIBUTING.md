# Contributing

Thanks for helping. Fixes, new blocks in `lumi.js`, examples and better docs are all welcome.

- Keep the remote a single page with no build step: `index.html`, `lumi.js` and `app/`.
- Test on a real light if you can, and say in the pull request what you tried it on (phone, browser, light).
- One change per pull request.
